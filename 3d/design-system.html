Design system · v1.0

Clear, calm, bold.

The tokens and components behind the Agro Alim Grup website. Neutral surfaces let the glass and the print take the stage; one action blue and one foil gold carry meaning; type does the heavy lifting so every section can be scanned in a second.

Open the websiteJump to components

01 · Principles

Four rules for every screen.

Product first

Surfaces stay neutral so the bottle, the foil and the ink are the only colour on screen.

One idea per block

Eyebrow → headline → one-line lead → content. Headlines are statements, not labels.

Scan in a second

Numbers, short specs, meters and tags. Paragraphs never exceed ~70 characters per line.

Motion explains

Animation shows how things work (the print processes) or where you are. Everything respects reduced motion.

02 · Color

A cool neutral ramp, two accents.

Inter, set tight and big.

05 · Motion

Ease out, never bounce twice.

Entrances use --ease-out over 700–1100 ms; state changes use 150–420 ms. The spring curve is reserved for toggles and small icons. Click a track to play it.

--ease-outcubic-bezier(.16, 1, .3, 1) · entrances, reveals
--ease-in-outcubic-bezier(.65, 0, .35, 1) · curtains, page moves
--ease-emphcubic-bezier(.2, 0, 0, 1) · emphasised UI
--ease-springcubic-bezier(.34, 1.4, .64, 1) · switches, icons
