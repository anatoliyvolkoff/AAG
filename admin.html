Connection

Changes are saved to the website's GitHub repository. Your hosting republishes the site automatically, usually within a minute.

How to get an access token
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose this site's repository.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  4. Generate, copy the token and paste it above. It is stored only in this browser, never in the site.

No token? You can still edit here and use Download JSON, then replace content/content.json in the repository manually.
